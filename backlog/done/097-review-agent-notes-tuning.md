# 097 — Review agent: notes → algorithm-tuning suggestions

**Epic:** strategy

## Context

Human reviews snapshot PNGs (backlog 095, 096) and records free-text verdicts
in same-name `.txt` sidecars. We now want an agent that closes the loop:
read those notes, cross-reference the actual analysis output, and produce
concrete suggestions for changing the algorithm to fix the flagged problems.

## Workflow (end state)

```
backtest → PNGs (+ notes sidecars) → human annotates .txt
        → review agent reads .txt + analysis output
        → suggests tuning changes to the algorithm
```

The agent is a tool/prompt layer over the existing analysis output, not a
new runtime analysis pass. It consumes:

1. All note sidecars in a snapshots dir (path + `note_text` from 096).
2. The structured JSON output (`run --output-json`) for the same run —
   provides price/fact context around each noted snapshot (facts, entry/stop/
   target, result, pnl, rejections, pattern geometry).
3. Strategy config / DSL source (the thing to actually change).

It correlates each note to its snapshot and emits targeted, actionable
suggestions: which rule/threshold/param to change, why (the note + evidence),
and expected effect.

## Scope

A CLI command `marketatlas review` (or `notes-review`) that assembles the
context bundle and yields suggestions. The actual "advice" is generated by an
LLM-driven step that consumes the assembled context — the CLI owns gathering,
matching, and formatting; the tuning recommendation itself is the agentic
output.

## Requirements

- [ ] `marketatlas review --snapshots DIR [--output-json F] [--strategy S]`
      command in `cli/commands.py` + subparser in `cli/__init__.py`.
- [ ] Auto-find the structured JSON for the run if `--output-json` omitted:
      look for the matching `*.json` (per-instrument) whose basename prefix
      aligns with the snapshot dir, else require explicit flag.
- [ ] Join notes ↔ POIs: reuse `locate_pois` on the JSON; match by
      `snapshot_basename(poi)` ↔ note filename. Orphan notes (no matching POI)
      and unreviewed POIs (no note) are both reported, not silently dropped.
- [ ] Context bundle per noted snapshot: basename, note text, POI record
      (kind, symbol, date, entry/stop/target, result/pnl or reject reason /
      pattern), plus trimmed fact context from JSON.
- [ ] LLM/agent step: emit structured suggestions
      (file/rule → change → rationale → expected effect) referencing note
      evidence. Prompt template lives in `src/marketatlas/review/prompt.py`.
- [ ] Output suggestions to stdout (text) and optional `--json` file
      (machine-readable) for later automation.
- [ ] Zero-suggestion run (no notes) exits cleanly with note.
- [ ] Deterministic fallback when no LLM provider configured: print the
      assembled context bundle and a "no provider" marker instead of failing.

## Testing

- [ ] `tests/test_review.py`: note↔POI join, orphan/unreviewed reporting,
      context bundle shape for each kind (trade/pattern/rejection).
- [ ] Prompt assembly: golden text snippet for a fixture bundle.
- [ ] CLI smoke: `review --snapshots` with fixture dir + fixture JSON;
      assert exit codes and empty/absent-note paths.
